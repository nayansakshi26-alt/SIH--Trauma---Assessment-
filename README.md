  # AI-Based Real-Time Stress & Trauma Assessment Module

## About the Project

This project proposes an AI-enabled, real-time Stress and Trauma Assessment Module for the National Helpline Against Atrocities (NHAA 14566).

The system analyzes voice, speech, text, and emotional indicators to assess the caller's stress level and generate a Stress Vulnerability Index (SVI) from 0–100.

It categorizes cases into Low, Moderate, High, and Critical risk levels and supports counsellors in prioritizing cases and responding to emergencies more efficiently.

The system follows a human-in-the-loop decision-support approach, where AI supports trained human professionals and does not replace them.

## Key Features

- Voice and Speech Analysis
- Text and Narrative Analysis
- Emotion Analysis
- Stress Vulnerability Index (SVI)
- Crisis Detection and Escalation
- Counsellor Dashboard
- Multilingual Support
- Privacy and Secure Data Handling

## Technology Stack

- AI & Speech: Whisper, Pyannote.audio
- NLP: PyTorch, Hugging Face
- Backend: Python, FastAPI, REST API
- Database: PostgreSQL, Redis
- Frontend: React, Tailwind CSS
- Deployment: Docker, Kubernetes
- Security: Encryption, Role-Based Access Control (RBAC)
